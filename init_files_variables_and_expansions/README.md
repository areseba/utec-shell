# init_files_variables_and_expansions

Contiene script de Shell, archivos de inicialización, variables y expansiones

## Script

- `0-alias` Crea un script que cree un alias.

- `1-hello_you` Crea un script que imprima hola user, donde user es el usuario actual de Linux.

- `2-path` El camino hacia el éxito es tomar acciones masivas y decididas
Añade /action a la PATH. /action debe ser el último directorio que el shell revisa al buscar un programa.
