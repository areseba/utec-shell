# io_redirections_and_filters

La carpeta contiene script de Shell, redirecciones de entrada/salida y filtros

## Script

- `0-hello_world` Escribe un script que imprima “Hello, World”, seguido de una nueva línea en la salida estándar.

- `1-confused_smiley` Escribe un script que muestre un emoticono confundido "(Ôo)'

- `2-hellofile` Muestra el contenido del archivo /etc/passwd.

- `3-twofiles` Mostrar el contenido de /etc/passwd y /etc/hosts

- `4-lastlines` Muestra las últimas 10 líneas de /etc/passwd

- `5-firstlines` Muestra las primeras 10 líneas de /etc/passwd
